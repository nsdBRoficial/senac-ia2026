# 🧮 Calculadora Python

Uma calculadora interativa e modular desenvolvida em Python, com suporte a operações aritméticas fundamentais, cálculos avançados e histórico em memória da sessão.

---

## 🚀 Funcionalidades

- ➕ **Adição** (`+`)
- ➖ **Subtração** (`-`)
- ✖️ **Multiplicação** (`*`)
- ➗ **Divisão** (`/`) com proteção contra divisão por zero
- ⚡ **Potenciação** (`^`)
- 📐 **Raiz Quadrada** (`√`) com validação de números negativos
- 📊 **Porcentagem** (`%`)
- 📜 **Histórico de Cálculos** da sessão atual
- 🛡️ **Tratamento de Exceções**: impede falhas caso o usuário digite texto ou entradas inválidas
